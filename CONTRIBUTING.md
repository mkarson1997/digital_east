# Contributing

Contributions that improve accessibility, performance, responsive behavior, documentation, content structure, or maintainability are welcome.

## Before opening a pull request

1. Keep the Arabic RTL experience intact.
2. Avoid adding unnecessary runtime dependencies.
3. Verify affected pages locally.
4. Check navigation, responsive layouts, and basic keyboard usability.
5. Keep commits focused and explain the reason for the change.

## Pull requests

Include a short summary, testing notes, and screenshots for visible UI changes when useful.

For larger changes, open an issue first so the scope can be discussed.
